# S7 影子观察与切换手册

## 一、影子模式开关

已安装的模块会接管同名内置源。为逐源对比，可以把某个源临时切回内置实现：

```
NativeRequest {"action":"shadow","source":"jcydm","command":"builtin"}   # 切回内置
NativeRequest {"action":"shadow","source":"jcydm","command":"module"}    # 恢复模块
NativeRequest {"action":"shadow","command":"list"}                       # 查看每个源当前归属
```

开关只作用于当前进程内存，不改磁盘、不改清单，重启即回到默认（模块优先）。

## 二、对比工具

```bash
# 编译带影子开关的 probe
cd native && GOTOOLCHAIN=local GOPROXY=https://goproxy.cn,direct \
  /data/local/tmp/opencode/go124/bin/go build -o /data/local/tmp/opencode/probeShadow ./cmd/probe

# 对比某个源（同一请求跑两遍）
python3 scripts/shadow_compare_run.py \
  /data/local/tmp/opencode/probeShadow /data/local/tmp/opencode/modtest7 jcydm \
  '{"action":"catalog","source":"jcydm","page":1}'
```

输出：

```json
{"source":"jcydm","action":"catalog","builtin":{"items":60,"ids":[...]},
 "module":{"items":60,"ids":[...]},"id_overlap":1.0,"pass":true}
```

`pass=true` 要求两边 sourceId 集合重叠率 ≥ 99%，且错误状态一致。

## 三、验收标准

| 阶段 | 周期 | 通过条件 |
|---|---|---|
| 影子对比 | 连续 3 天 | 11 个源 catalog 对比 `pass=true`；detail 集数一致；resolve 可达性一致 |
| 切白名单 | 第 4 天 | 模块保持默认接管，观察崩溃率与用户反馈 |
| 删旧代码 | 第 11 天 | 7 天无回退，删除对应 `provider_*.go`，同步删 `source_registry.go` 条目 |
| 收紧基线 | 删完后 | `python3 scripts/check_provider_freeze.py --update`，让「内置源只减不增」成为硬约束 |

## 五、回滚

- 影子期内：删掉 `modules/<id>/` 即回到内置实现
- 切白名单后：用 `shadow` 动作切回内置，或卸载模块
- 删掉 provider 后：从 git 恢复文件，同步恢复注册表条目，重新 `check_provider_freeze.py --check`
