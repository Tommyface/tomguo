# 站源插件规范

给「聚合短剧」写站源插件的完整契约。按本文档写的模块，装进 App 即可用，不需要重新发版。

---

## 一、插件是什么

一个插件 = 一个文件夹，两个文件：

```
<插件目录>/
├── manifest.json   元信息
└── main.js         实现
```

打包成 zip 后，在 App 的「设置 → 站源模块 → +」安装。安装后立即出现在站源列表、搜索、同名换源里。

**运行时**：纯 Go 的 goja 引擎，无 CGO，不需要 Node。

## 二、manifest.json

```json
{
  "id": "huangdou",
  "name": "黄豆短剧",
  "version": "1.0.0",
  "description": "AES-256-CBC + HMAC-SHA256 + gzip 的加密接口站源",
  "runtime": "js",
  "api": 1,
  "adult": true,
  "hosts": ["iwgsqufx.cc", "eyeonneb.cc"],
  "capabilities": ["search"],
  "allowEmptyCatalog": false
}
```

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | string | 小写字母 / 数字 / 下划线 / 连字符，**最长 32**，必须唯一 |
| `name` | ✅ | string | 显示名，出现在站源列表 |
| `version` | — | string | 三段版本号 `1.0.0` |
| `description` | — | string | 一句话说明，显示在模块列表 |
| `runtime` | ✅ | string | 固定 `"js"` |
| `api` | ✅ | int | 接口版本，当前必须写 `1` |
| `adult` | ✅ | bool | 是否成人内容。**必填**，漏了拒绝加载 |
| `hosts` | — | string[] | 会访问的域名，仅作说明与审计 |
| `capabilities` | — | string[] | 见下表，未列出的能力不会调用 |
| `allowEmptyCatalog` | — | bool | 允许空分类（示例/测试模块用）。**生产模块不要开**，开了不参与同名换源 |

### capabilities 取值

| 值 | 含义 |
|---|---|
| `search` | 支持在线搜索（同名换源必需） |
| `cover` | 提供封面地址 |
| `recommendations` | 提供推荐流 |
| `danmaku` | 提供弹幕 |
| `rankings` | 提供榜单 |
| `metadata` | 提供补充元信息 |
| `catalogState` | 提供目录状态 |

写错任何一个值 → 整个模块拒绝加载，报「未知的模块能力」。

### 校验规则

加载时逐项检查，任一失败整个模块不注册：

- `id` 不符合正则 → 「模块标识只能用小写字母、数字、下划线和连字符，最长 32 个字符」
- `name` 为空 → 「模块缺少名称」
- `runtime` 不是 `js` → 「不支持的模块运行时」
- `api` 不是 1 → 「模块接口版本为 N，当前应用支持 1」
- `adult` 缺失 → 「模块缺少 adult 声明」
- `capabilities` 有未知值 → 「未知的模块能力」
- `main.js` 超过 4 MB → 「main.js 超过 4 MB」
- JS 语法错误 → 「模块脚本编译失败」

## 三、main.js 的五个导出函数

模块用 CommonJS 写法。宿主会注入 `module`、`exports`、`host` 三个变量：

```js
module.exports = {
  categories(force) { },
  catalogPage(page, category) { },
  search(page, query) { },
  detail(sourceId) { },
  resolveMedia(task) { },
};
```

**全部必须是同步函数**。返回 Promise 会报「模块函数 X 不能是异步函数」。

| 函数 | 入参 | 返回 | 何时调用 |
|---|---|---|---|
| `categories` | `force: bool` | `[{id, name}]` | 打开分类栏 |
| `catalogPage` | `page: int`（从 1 起）、`category: string`（空串=全部） | `{items, hasMore, warning?}` | 浏览列表 |
| `search` | `page: int`、`query: string` | `{items, hasMore, warning?}` | 搜索、同名换源 |
| `detail` | `sourceId: string` | `{drama, chapters}` | 打开详情、拉分集 |
| `resolveMedia` | `task` | `{url, referer?, playlist?, hlsKey?, durationMs?}` | 点播放 |

`warning` 非空时，界面会显示该提示但不中断。

## 四、数据形状

### 4.1 items 里的一项（剧集）

最少只需三个字段：

```js
{
  id: host.dramaId(sourceId),   // 必须：全局唯一 id
  source: host.source,           // 必须：插件 id
  sourceId,                      // 必须：站点内部的 id
  title: '剧名',                 // 建议
  name: '剧名',                  // title 的别名，二选一
  cover: 'https://...',          // 可选
  totalEpisode: 21,              // 可选：总集数
  episodeCount: 21,              // totalEpisode 的别名
  category: '短剧',              // 可选
  desc: '简介',                  // 可选
  intro: '简介',                 // desc 的别名
  vip: 'unknown' | 'free' | 'vip', // 三态，未声明视为 unknown
  freeEpisodeCount: 20,           // 可选：免费集边界（黄果源已有此概念）
}
```

**id 的三种写法**（推荐第一种）：

```js
id: host.dramaId('abc123')        // → 'huangdou:abc123'
id: 'huangdou:abc123'             // 手写等价形式
id: 'abc123'                      // 也接受，但同名换源时可能冲突
```

### 4.2 detail 返回

```js
{
  drama: { /* 同 4.1 的一项 */ },
  chapters: [
    {
      id: host.chapterId(sourceId, '1'),  // 必须
      source: host.source,                 // 必须
      title: '第1集',                      // 必须
      currentEpisode: 1,                   // 必须：集数，用于排序与「下一集」
      vip: 'unknown' | 'free' | 'vip',      // 三态，未声明视为 unknown
      pageUrl: 'https://...',              // 可选：该集页面地址
    },
  ],
}
```

**`currentEpisode` 必须是数字**。写成 `"1"` 字符串时，排序会出错。

### 4.3 resolveMedia 的入参 task

```js
{
  dramaId: 'huangdou:abc123',    // 带插件前缀的完整 id
  dramaTitle: '剧名',
  chapter: {                      // detail 里返回的那一项
    id: 'huangdou:abc123:1',
    source: 'huangdou',
    title: '第1集',
    currentEpisode: 1,
  },
  index: 0,                       // 0 基索引
  total: 21,
}
```

**从 `task.dramaId` 取 sourceId**：

```js
resolveMedia(task) {
  const sourceId = String(task.dramaId).split(':')[1];
  const seq = Number(task.chapter.currentEpisode);
  // ...
}
```

### 4.4 resolveMedia 返回

```js
{ url: 'https://cdn.example.com/xxx.m3u8', referer: 'https://site.com/' }
```

| 字段 | 说明 |
|---|---|
| `url` | 必须。m3u8 / mp4 直链 |
| `referer` | 强烈建议。多数 CDN 校验防盗链 |
| `playlist` | 可选。已拉取的清单文本，省一次请求 |
| `hlsKey` | 可选。AES-128 的 16 字节密钥 |
| `durationMs` | 可选。时长，用于进度条 |
| `variants` | 可选。多码率，元素同本结构 |

## 五、host 能力全表（24 个）

宿主注入的 `host` 对象。**只能用这些**，没有 `require`、没有 `fetch`、没有 `window`、没有 `localStorage`。

### 5.1 标识

| 函数 | 返回 | 说明 |
|---|---|---|
| `host.source` | string | 当前插件 id |
| `host.dramaId(sourceId)` | string | `'<插件id>:<sourceId>'` |
| `host.chapterId(sourceId, key)` | string | `'<插件id>:<sourceId>:<key>'` |

### 5.2 网络

```js
const res = host.fetch({
  method: 'GET',              // 默认 GET
  url: 'https://...',         // 必须 http/https
  headers: { Referer: '...' },
  body: '',                   // 文本请求体
  bodyBase64: '',             // 二进制请求体（优先于 body）
  timeoutMs: 20000,           // 默认取应用配置
  limit: 0,                   // 响应上限，0 = 应用默认
  followRedirects: false,
  resolveIP: '104.21.43.118', // 钉 IP，Host 头与 TLS SNI 仍是原域名
  cacheKey: 'huangguo:publish',  // 可选：跨模块共享缓存键
  cacheTtlSec: 1800,             // 可选：缓存秒数，0 = 应用默认（30 分钟）
});
// res = { status: 200, headers: {...}, body: '...', bodyBase64: '...' }
```

**关键点**：

- `fetch` 走应用统一的请求栈：限速、重试、代理、TLS 指纹全部复用，模块无法绕过
- **二进制必须用 `bodyBase64`**。用 `body` 传二进制会被 UTF-8 转换破坏
- 响应也是：文本用 `res.body`，密文/图片用 `res.bodyBase64`
- `resolveIP` 用于绕过本地 DNS 污染。先用 `host.resolveDNS` 拿真实 IP，再钉上去
- `cacheKey` 用于发布页这类多个源共用的入口：同 key 只发一次请求，默认缓存 30 分钟。
  **只缓存 2xx 响应**，失败不缓存；键名建议带站点前缀（`站点:用途`）避免跨源撞车

### 5.3 DNS

```js
host.resolveDNS('huangguoai.com');  // → ['208.43.237.140', ...]
```

走 DoH（`doh.pub` → 阿里 → Cloudflare），返回 A 记录。本地 DNS 被污染时用它。

### 5.4 哈希

```js
host.md5(data)              // → Uint8Array(16)
host.sha1(data)             // → Uint8Array(20)
host.sha256(data)           // → Uint8Array(32)
host.hmacSha256(key, data)  // → Uint8Array(32)
```

`data` 可以是字符串或 `Uint8Array`。

### 5.5 对称加密

```js
host.aesCbcEncrypt(key, iv, data)   // key: 16/24/32 字节，iv: 16 字节，data: 16 的倍数
host.aesCbcDecrypt(key, iv, data)
host.aesGcmSeal(key, nonce, plain, aad)
host.aesGcmOpen(key, nonce, sealed, aad)   // 校验失败抛错
```

**AES-CBC 不做自动填充**。PKCS7 要自己写：

```js
function pad(bytes) {
  const fill = 16 - (bytes.length % 16 || 16) + 16;
  const amount = bytes.length % 16 === 0 ? 16 : 16 - (bytes.length % 16);
  const out = new Uint8Array(bytes.length + amount);
  out.set(bytes, 0);
  out.fill(amount, bytes.length);
  return out;
}
```

### 5.6 密钥协商

```js
const pair = host.ecdhP256KeyPair();
// pair = { privateKey: Uint8Array(32), publicKey: Uint8Array(65) }

host.ecdhP256(privateKey, peerPublicKey);   // → Uint8Array(32) 共享密钥
host.hkdfSha256(secret, salt, info, length);  // → Uint8Array(length)，上限 1024
```

### 5.7 压缩

```js
host.gzip(data)      // → Uint8Array
host.gunzip(data)    // → Uint8Array
```

### 5.8 编解码

```js
host.base64Encode(bytes)   // → string（标准 base64，带 = 填充）
host.base64Decode(text)    // → Uint8Array，非法输入抛「Base64 内容无效」
host.bytes('文本')          // → Uint8Array（UTF-8）
host.utf8(bytes)           // → string
host.randomBytes(16)       // → Uint8Array，上限 1024
```

base64url 要自己转：

```js
function b64u(bytes) {
  return host.base64Encode(bytes).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}
```

### 5.9 模块存储

跨调用保留的键值存储，按模块隔离，宿主管配额与过期。

```js
host.storageSet('token', 'eyJhbGciOi...', 6 * 24 * 3600);   // ttlSec，0 = 不过期
const token = host.storageGet('token');                      // 不存在或已过期返回 ''
host.storageDelete('token');
```

| 项 | 限制 |
| --- | --- |
| 键长 | ≤ 128 字符，不能含控制字符，不能为空 |
| 单值 | ≤ 64 KB |
| 每模块总量 | ≤ 256 KB / 128 条 |
| 过期时间 | 0 = 不过期；最大 30 天，超过自动截断 |
| 淘汰 | 超出配额时按「最早过期」淘汰；**没有过期时间的条目不淘汰** |
| 生命周期 | 卸载模块时清空；不写入文件，重启应用后丢失 |

需要重启后仍有效的数据，由模块在首次调用时重新获取（如重新登录换令牌）。

## 六、运行环境限制

| 项 | 限制 | 超了会怎样 |
|---|---|---|
| `main.js` 大小 | 4 MB | 模块拒绝加载 |
| 单次调用超时 | 60 秒 | 抛 `context deadline exceeded` |
| 并发实例 | 4 个 | 排队等待 |
| `randomBytes` | 1024 字节 | 抛「随机字节数无效」 |
| `hkdfSha256` | 1024 字节 | 抛「HKDF 长度无效」 |
| 响应体 | 应用默认上限 | 抛「响应超出大小上限」 |
| 单次 `fetch` | 必须 http/https | 抛「请求地址必须是 http/https」 |

**没有的东西**：`setTimeout`、`setInterval`、`Promise`（异步）、`require`、`process`、`window`、`document`、`localStorage`、`eval`、`console`。

需要延时用同步忙等（不推荐）：

```js
const start = Date.now();
while (Date.now() - start < 500) {}
```

## 七、错误处理

抛 `Error` 即可，App 会把 `error.message` 显示给用户：

```js
if (!res.status || res.status !== 200) {
  throw new Error('站点返回 HTTP ' + res.status);
}
if (payload.code !== 200) {
  throw new Error('接口错误 ' + payload.code + '：' + (payload.msg || '未知'));
}
```

**错误信息会直接显示在界面上**，所以写人话，别写 `undefined is not a function`。

需要在详情页之外单独提示时，用 `warning` 字段：

```js
return { items, hasMore: false, warning: '该源当前仅提供部分剧集' };
```

## 八、四种典型站点类型

### 8.1 明文 JSON 接口

```js
function get(path) {
  const res = host.fetch({ url: BASE + path, headers: { 'User-Agent': UA } });
  if (res.status !== 200) throw new Error('HTTP ' + res.status);
  return JSON.parse(res.body);
}

module.exports = {
  catalogPage(page) {
    const data = get('/api/list?page=' + page);
    return {
      items: data.list.map(row => ({
        id: host.dramaId(String(row.id)),
        source: host.source,
        sourceId: String(row.id),
        title: row.title,
        cover: row.cover,
        totalEpisode: row.episode_count,
      })),
      hasMore: data.list.length >= 20,
    };
  },
};
```

### 8.2 服务端渲染 HTML（正则抓）

参考 `huanggua` 插件（171 行）。要点：

- **按容器块切分**，不要用字符窗口，否则会跨卡片串行污染
- 卡片里的角标（集数、热度）按出现顺序配对
- 播放地址用 `/(https?:\/\/[^"'\s\\]+\.m3u8[^"'\s\\]*)/` 抓，注意还原 `&amp;` 和 `\u0026`

### 8.3 加密接口（AES / HMAC）

参考 `huangdou` 插件（304 行）。典型流程：

```js
const rid = requestId();
const key = host.hmacSha256(host.bytes(PLATFORM_KEY), hexToBytes(rid.replace(/-/g, '')));
const iv = host.randomBytes(16);
const plain = host.gzip(host.bytes(JSON.stringify(payload)));
const body = concat(iv, host.aesCbcEncrypt(key, iv, pad(plain)));

const res = host.fetch({
  method: 'POST',
  url: BASE + path,
  bodyBase64: host.base64Encode(body),   // 关键：二进制走 base64
  headers: { requestId: rid, sign: ... },
});

const raw = host.base64Decode(res.bodyBase64);   // 关键：响应也是二进制
const text = host.utf8(host.gunzip(unpad(host.aesCbcDecrypt(key, raw.slice(0,16), raw.slice(16)))));
```

### 8.4 苹果 CMS（maccms）

参考 `heitao` 插件（190 行）。结构固定：

```
列表    /index.php/vod/type/id/{tid}/page/{n}.html
详情    /index.php/vod/detail/id/{id}.html
播放页  /index.php/vod/play/id/{id}/sid/1/nid/{n}.html
播放器  /index.php/vod/player/id/{id}/nid/{n}/sid/1.html   ← 真正地址在这里
```

播放地址在 player 页的 `player_aaaa={...}` JSON 里，取 `url` 字段。有年龄门时加 cookie。

## 九之四、封面域名白名单

宿主可用环境变量 `TOMGUO_COVER_HOSTS` 限制模块返回的封面域名（逗号分隔）。未设置时不校验。

模块侧可主动检查：

```js
if (!host.coverAllowed(cover)) {
  cover = '';   // 交给 App 显示占位图
}
```

`localhost`、IP 字面量、非 http(s) 地址一律拒绝。对应 AGENTS.md 的「不看、不下站源图片」约定——模块只返地址，宿主不下内容；白名单再挡一层把地址指向本地或任意 IP 的情况。

## 九之三、VIP 三态

`vip` 字段是三态字符串，不是布尔值：

| 值 | 含义 |
| --- | --- |
| `'unknown'` | 未确认（默认）。**未知不会覆盖已知**——先查到未知、后又查到 free/vip 时才更新 |
| `'free'` | 确认免费 |
| `'vip'` | 确认需要会员 / 金币解锁 |

Go 侧 `Drama.VIP *bool` 用 nil 表 unknown、`Chapter.VIP bool` 由宿主按三态解析填充。
模块没写 `vip` 时按 `'unknown'` 处理，不要写 `false`——那会把「没查过」误报成「确认免费」，界面上开始骗用户。

## 九、写插件的检查清单

写完一条一条过：

- [ ] `manifest.json` 里 `id` 全小写、`api` 是 `1`、`adult` 是布尔值
- [ ] 五个导出函数都是**同步**的
- [ ] `items` 每项都有 `id` / `source` / `sourceId`
- [ ] `chapters` 每项 `currentEpisode` 是**数字**
- [ ] 二进制请求体用 `bodyBase64`，不用 `body`
- [ ] 二进制响应用 `res.bodyBase64`，不用 `res.body`
- [ ] 所有 `fetch` 都设了 `timeoutMs`
- [ ] 错误信息是给用户看的中文
- [ ] 域名被污染时用 `host.resolveDNS` + `resolveIP`
- [ ] 没有用 `Promise` / `setTimeout` / `require`

## 九之二、版本目录与回滚

模块支持按版本并存，安装时不再原地覆盖：

```
modules/<id>/versions/1.0.0/manifest.json
modules/<id>/versions/1.0.0/main.js
modules/<id>/versions/1.0.1/manifest.json   ← 当前生效
modules/<id>/versions/1.0.1/main.js
```

- `moduleActiveDir` 取字典序最大的版本目录；
- 升级失败保留旧版本，删掉坏版本目录即可回退；
- 没有 `versions/` 时仍读扁平目录，历史安装照常可用；
- 清单 `mainSha256` 与版本目录内的 `main.js` 仍是同一套校验。

## 十一、交付方式

### 开发期

```bash
cd native/module_example
python3 -c "
import zipfile, os
```

### 正式
